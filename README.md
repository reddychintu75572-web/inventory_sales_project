# Inventory & Sales Management System

This is a simple Inventory and Sales Management System developed using Flask and MySQL.

## Features

- Add and view products
- Manage product stock
- Add and view customers
- Create sales
- Check product stock before sale
- Calculate total amount
- Reduce stock after sale
- Generate and print sales bill

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Database

Database name:

`inventory_sales_db`

Tables:

- products
- customers
- sales

## How to Run

1. Install Python and MySQL.
2. Install the required Python packages.
3. Create the MySQL database and tables.
4. Add the MySQL password in the `.env` file.
5. Run the Flask application:

```bash
python app.py
